# Contributing

Thanks for helping keep this list correct.

## Report an operator

Open an issue with these 3 details.

- The search you ran, copied as text.
- The tab you used, Latest or Top.
- What X returned & the date.

## Change the list

- `operators.json` holds every operator. The README tables are built from it.
- Edit `operators.json` & the prose in `README.md`. Leave the tables to the
  weekly run.
- Give each operator 1 example that returns posts on X today.
- Keep each description to 1 or 2 short sentences.

## Pull requests

Open a pull request against `main`. A maintainer runs your example on X before
merging.
