# Security policy

This repository holds documentation only. It runs no code & stores no secrets.

## Report a vulnerability

Email [support@xquik.com](mailto:support@xquik.com) with the subject
`Security report`. Use the same address for a finding in the Xquik product.

Do not open a public issue or pull request for a security finding.

## Response

We send a first reply within 3 business days & a triage result within 14 days.

## Rewards

Rewards can be monetary & depend on the bug's impact. Xquik decides each reward,
& not every report earns one. The
[bug bounty & vulnerability disclosure policy](https://xquik.com/en/vulnerability-disclosure)
lists the scope & test rules.
